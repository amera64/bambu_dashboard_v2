# Bambu Dashboard 3D-Printable Enclosure

This enclosure was designed for the 2.8-inch ESP32-S3 touchscreen used by the Bambu P1S Dashboard project.

## Included Parts

- `2.8 inch ESP32 Flip up Display case back.stl`
- `2.8 inch ESP32 Flip up Display case front.stl`
- `2.8 inch ESP32 Flip up Display_adaptor.stl`

Editable STEP files are also included for users who want to customize the enclosure.

## Recommended Print Settings

- Material: PLA or PETG
- Layer height: 0.20 mm
- Walls: 3
- Top and bottom layers: 4
- Infill: 15–20%
- Supports: None, unless required by your printer or orientation
- Brim: Optional

## Suggested Orientation

Print both pieces with their largest flat surface against the build plate.

## Parts Needed
A USB-A to USB-B micro cable approxmately 200mm in length is ideal. I speculate that a cable as short as 150mm might just reach,
and if the cable was longer, the enclosure has space to tuck in the excess.

6 x M3 x 12mm countersunk bolts for attaching the rear to the front pieces.

2 x M3 x 12mm bolts for attaching the enclosure to the adaptor.

## Assembly

1. Insert the display into the front bezel.
2. Make sure the screen and USB connector are correctly aligned.
3. Secure the circuit board to the internal mounting posts.
4. Route the USB cable through the enclosure opening.
5. Install the rear cover using the appropriate screws.
6. Do not overtighten the screws, as this may damage the printed mounting posts.

## Compatibility

This enclosure is designed specifically for the display model identified in the main project documentation. Other ESP32-S3 displays may use different board dimensions, connector locations, or mounting-hole spacing.
